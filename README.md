# Femiknit Storefront

Production-ready Next.js App Router ecommerce storefront for an Indian ethnic wear brand.

## Stack

- Next.js 16 App Router
- React 19
- Tailwind CSS 4
- Framer Motion
- Lucide React icons

## Features

- Sticky ecommerce header with offer ticker, search, wishlist, account, and cart badges
- Hero carousel with remote optimized imagery and animated controls
- Sticky sidebar filters for category, size, color, price, age group, occasion, and keyword search
- Product cards with framed imagery, hover slideshow, progress bars, wishlist toggle, cart state, swatches, and animated CTAs
- Traditional toran SVG line art with swinging bells, rotating mandalas, age-group portraits, festive feature block, trust badges, and footer newsletter

## Run Locally

Install Node.js 20.9 or newer, then run:

```bash
npm install
npm run dev
```

This workspace also includes a local portable Node runtime. To preview without installing Node globally:

```powershell
.\start-preview.ps1
```

For production verification:

```bash
npm run typecheck
npm run build
```
